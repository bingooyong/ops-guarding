# AI Knowledge Index

This directory stores long-term knowledge for AI agents working on `ops-guarding`.

## Documents

- `session-summary.md`: completed assets, verification evidence, and residual risks.
- `project-context.md`: project purpose, architecture, commands, and validation contract.
- `reusable-patterns.md`: delivery, baseline, review-fix, concurrency, and evidence patterns.
- `troubleshooting.md`: known symptoms, causes, fixes, and prevention rules.
- `ai-agent-rules.md`: operating constraints for Codex, Claude Code, and future agents.
- `task-chain-regression-tests.md`: test strategy for end-to-end task lifecycle coverage.
- `production-hardening.md`: security, deployment, observability, and HA hardening checklist.

## Usage

Read this directory before making project-wide changes, preparing completion reports, or diagnosing validation failures.
